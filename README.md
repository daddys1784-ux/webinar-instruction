# Инструкция по вебинарам — Корпоративный Университет

Многостраничный сайт с пошаговой инструкцией.

## Как правильно открыть сайт

### Локально (рекомендуется для проверки)
1. Скачайте или клонируйте репозиторий.
2. Откройте файл `index.html` двойным кликом **или** через локальный сервер.

### На GitHub Pages (чтобы фото работали в браузере)
1. Зайдите в репозиторий → **Settings** → **Pages**.
2. Source: **Deploy from a branch**.
3. Branch: `main` (или `master`), folder: `/ (root)`.
4. Сохраните. Через 1–2 минуты сайт будет доступен по адресу:
   `https://ВАШ_ЛОГИН.github.io/НАЗВАНИЕ_РЕПОЗИТОРИЯ/`

**Важно:**  
Если открывать HTML-файл прямо на странице GitHub (кнопка View / blob), картинки **не загрузятся**. Это ограничение GitHub, а не ошибка в файлах. Нужно именно GitHub Pages или локальное открытие.

## Структура (все файлы в одной папке)
```
website/
├── index.html
├── search.html
├── webinar.html
├── test.html
├── mobile.html
├── exit.html
├── styles.css
├── logo.svg
├── logo-green.svg
├── image1.png … image16.png
└── README.md
```

Все пути к картинкам — относительные (лежат рядом с HTML).  
После включения GitHub Pages всё откроется корректно.
